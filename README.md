# Etieno Douglas — Portfolio

Two sides of my work in one site: **Creative & Marketing** and **Leadership & Impact**.

- Static site: a single self-contained `index.html` (images and template downloads are embedded).
- No build step. Deployed on Vercel.

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy
Push to `main`. Vercel redeploys automatically once the project is connected to this repository.
